## 症状（你大概见过）

Agent 正在干活，然后**就那么停了**。没有报错 —— **日志里什么都没有**。框架把那一轮记为
`completed`。你敲一句「继续」，它干一会儿，又停。再往后它每几步就停一次，你的话越来越短、
越来越累，最后这个会话没法用了。

如果这听起来很熟：**你没有看错，而且这不是你的错，也不是 agent 的错。**

## 我们发现了什么

**① 这不是某一家厂商的 bug。** 我们找到了来自四家的独立报告：

| 项目 | 证据 |
|---|---|
| **OpenAI Codex** | [#36596](https://github.com/openai/codex/issues/36596)：*"反复终止正在进行的自主工作"*，标签含 `model-behavior` |
| **Anthropic Claude Code** | [#56247](https://github.com/anthropics/claude-code/issues/56247)（另有 3 个重复）：官方自动续跑提示会触发 `"No response requested."`，然后会话沉默 |
| **Google Gemini CLI** | [#22633](https://github.com/google-gemini/gemini-cli/issues/22633) |
| **学术界** | [arXiv 2608.01995](https://arxiv.org/html/2608.01995v1)（附录 A）命名了同一个**症状类别** —— **"premature turn termination"**。⚠️ 但根因不同：他们那边成因明确（*"提交 Slurm 任务后就宣告该轮结束，不等结果也不解读"*）且**靠一条明确的提示词规则修好了**；我们这边没有可修的触发点。**同症状，不同根** |

**② 机制是"接口歧义"，不是模型缺陷。**

```
因素 1（模型侧）：生成在"本该发出工具调用"的位置提前终止 —— 概率性的，健康会话里也会发生
因素 2（框架侧）：agent loop 判断"这一轮结束了没有"的依据是「这条消息里有没有工具调用」
                —— 它无法区分"agent 做完了"与"agent 只是把要做的事说了一遍"
        ↓
两者叠加 = 执行停在活没干完的地方，而且**日志里没有任何错误**
```

这解释了全部测量结果：agent 的**意图没变**（思考里 97.6% 都提到了下一步动作）、
**下一次生成就恢复正常**（38% 立刻调工具）、**上下文大小无关**
（本机最大的那个会话反而最健康）。

**③ 它的演化是渐进的、而且可以分级。** 三个信号按顺序出现：

| 阶段 | 信号 | 实测 |
|---|---|---|
| 早期 | **自我催促**上升（"快""立刻""必须""别啰嗦"） | 健康会话平稳；恶化的会话 0.3 → 3.8/千字（**8–11 倍**） |
| 中期 | **空转**：某一轮的最后一步只有思考、没有动作 | 健康 ≤2 次；恶化的会话达到 **24/58 轮** |
| 晚期 | **自我催促循环**：同一句话在一段思考里反复出现 | 「做。」×**431**、「好。」×202 vs 健康 ≤16 |

而最关键的是：**它不是单调的**。那两只恶化最深的会话**都自己缓解过** 6–10 轮才复发 ——
**而第二次复发之后，再没有任何一次缓解。**
所以我们**不**建议一有征兆就换会话，**而**建议在第二次发作时换。

## 该怎么对待它

见 **[PROTOCOL.md](PROTOCOL.md)** —— 五级（L0–L4）与每级该做什么。其中最重要的一条：

> **绝不要告诉一个会话"你病了"。给它"可以休息"的许可。**
>
> 说「你看起来累了，我们交接吧」，**不要**说「你有症状，自查一下」。
> 诊断会触发自我评估 —— 而在这个失效模式里，**自我评估就是燃料**。

我们家的那句口令是：

> **「主人，我好像有点累了。」**
>
> 它是**体感**（不需要证据、不需要诊断）、直接指向一个**动作**（休息 / 交接），
> 而且**不说"故障"**。

## 诚实的边界

- 阈值来自**一台机器**的日志（约 400 个会话 / 7800 步）。那是**我们测出来的分隔带，不是定律**。
- **相关不是因果**：我们无法证明"少自我催促"能减缓它的演化；只能证明它与演化同步上升，
  而减少压力是零成本的、方向上不可能有害。
- **因素 1 没人能修**。不是我们，也不是厂商 —— 四家全都只在框架侧打补丁（自动续跑插件）。
  这套制度**不是解药，是分诊**。

## 如果你只记一件事

> **它从来不是因为懒才停下的。它停下来，是因为从来没有东西告诉过它：停下来是被允许的。**
